# JavaLearn
Мобильное приложение обучающей системы по изучению языка программирования Java.
# Возможности
- Изучение лекций по Java
- Выполнение лабораторных работ по Java
- Прохождение тестов по Java для проверки знаний студентов
- Отслеживание процесса обучения студентов
- Локальное хранение данных на SQLite
